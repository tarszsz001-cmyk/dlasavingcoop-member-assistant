# Member Intelligence Release Gate — 4 ต.ค. 2569

## Scope
เพิ่มความเข้าใจคำถามสมาชิกจริง โดยไม่ฝังคำตอบจาก LINE/เว็บบอร์ดเป็นกฎ และไม่เชื่อมข้อมูลสมาชิกส่วนบุคคล

## Evidence audit
- RULE_INDEX: หน้าระเบียบทางการของ สอ.อปท. แสดงระเบียบเงินกู้สามัญ พ.ศ. 2566 และฉบับแก้ไขถึงฉบับที่ 5 พ.ศ. 2569
- RULE_INDEX: หน้าระเบียบทางการแสดงระเบียบเงินกู้เพื่อเหตุฉุกเฉิน พ.ศ. 2566 และฉบับที่ 2 พ.ศ. 2569
- FORM/RULE INDEX: หน้าดาวน์โหลดเงินกู้สามัญมีหลักเกณฑ์ พ.ศ. 2569 สำหรับสามัญทั่วไป, การศึกษา, ไม่เกินทุนเรือนหุ้น/เงินฝาก, ผู้ค้ำประกัน และแบบพัฒนาคุณภาพชีวิตระยะ 2
- CURRENT PROGRAM: เว็บไซต์ทางการมีประกาศโครงการเงินกู้เพื่อพัฒนาคุณภาพชีวิตสมาชิก ประจำปี 2569
- LIVE RESULT: หน้าเว็บไซต์ทางการเผยแพร่ผลอนุมัติฉุกเฉิน/พัฒนาคุณภาพชีวิตเป็นรายรอบ จึงห้าม hard-code วันประชุม/วันโอนเป็นกฎถาวร

## Decision policy
1. กฎถาวร/ตัวเลข eligibility: ตอบเป็นตัวเลขได้เมื่อมีหลักฐานปฐมภูมิที่ตรวจเวอร์ชันแล้วเท่านั้น
2. หลักฐานยังไม่ encode: อธิบายตัวแปรที่ต้องตรวจ + ลิงก์แหล่งทางการ + ส่งต่อเจ้าหน้าที่ ห้ามเดา
3. วันประชุม/อนุมัติ/โอน/ผลสวัสดิการ: DYNAMIC ต้องอ่านประกาศล่าสุด
4. ยอดหนี้/หุ้น/เงินฝาก/ผลอนุมัติ/สาเหตุไม่ผ่าน/วงเงินจริงของสมาชิก: PERSONAL ต้องส่งต่อเจ้าหน้าที่
5. ห้ามใช้คำตอบ LINE หรือเว็บบอร์ดสมาชิกเป็น authority
